# URL Checker

Приложение для асинхронной проверки доступности URL.

Пользователь создаёт задание со списком URL, после чего они проверяются в фоновом режиме. Для каждого URL отображается статус обработки, HTTP-код, ошибка, время начала/окончания и длительность проверки.

Данные хранятся in-memory и сбрасываются после перезапуска backend.

## Стек

### Frontend

- React
- TypeScript
- Vite
- Zustand
- SCSS Modules

### Backend

- Node.js
- Express
- TypeScript

### Infrastructure

- Docker
- Docker Compose

## Возможности

- создание задания со списком URL;
- асинхронная обработка URL;
- HEAD-запрос для проверки каждого URL;
- до 5 одновременных запросов в рамках одного задания;
- одновременная обработка нескольких заданий;
- случайная задержка перед сохранением результата от 0 до 10 секунд;
- просмотр списка созданных заданий;
- просмотр детальной информации о задании;
- отображение прогресса и статистики;
- отмена задания;
- отмена URL, которые ещё не начали обрабатываться;
- автоматический polling активного задания;
- корректная остановка polling при смене активного задания.

# Запуск

Есть два способа запустить приложение:

- С помощью Docker
- Локально без Docker

***Перед запуском любым из вариантов, необходимо сделать pull ветки из git репозитория***

## Вариант 1 — Docker

Требования: 
- Docker
- Docker Compose
- Установка зависимостей отдельно не требуется.

### Запуск

**1. Настроить переменные окружения**

- Backend

    Создать файл:

        apps/server/.env

    Содержимое:

        PORT=3000
        CLIENT_URL=http://localhost:5173
- Frontend

    Создать файл:

        apps/client/.env

    Содержимое:

        VITE_API_URL=http://localhost:3000/api

**2. Из корневой директории проекта**

```bash 
docker compose up --build
```

- После запуска приложение будет доступно по адресу:

```
Frontend: http://localhost:5173

Backend API: http://localhost:3000
```

### Остановка

```bash
docker compose down
```

### Архитектура Docker

- Frontend работает через Nginx.
```
Browser
   │
   │ http://localhost:5173
   ▼
 Nginx
   │
   │ /api/*
   ▼
Express
   │
   │ :3000
   ▼
In-memory storage
```

## Вариант 2 — локальный запуск без Docker

Требования:
- Node.js 22+
- pnpm 10+

Проверить версии:

```
node -v
pnpm -v
```

### Запуск

**1. Установить зависимости**

    Из корневой директории проекта:

```
pnpm install
```

**2. Настроить переменные окружения**

- Backend

    Создать файл:

        apps/server/.env

    Содержимое:

        PORT=3000
        CLIENT_URL=http://localhost:5173
- Frontend

    Создать файл:

        apps/client/.env

    Содержимое:

        VITE_API_URL=http://localhost:3000/api

**3. Запустить backend в первом терминале**

```
pnpm --filter server dev
```

**4. Запустить frontend во втором терминале**

```
pnpm --filter client dev
```

**После запуска открыть:**

http://localhost:5173

# Ограничения

### Приложение использует in-memory storage.

- Это означает, что все задания будут потеряны после перезапуска backend.

- Отдельная база данных намеренно не используется в соответствии с условиями тестового задания.
